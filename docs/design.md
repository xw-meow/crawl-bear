# CrawlBear 设计规范 · 超级爬爬熊

> 版本 v1.0 · 2026-10-28
> 本文是 UI 的唯一设计依据。改界面之前先改这里，代码里的 token 与组件必须能从本文推导出来。

---

## 1. 一句话定位

**一只憨厚老实的小熊，替你把网页里的图片、视频、音乐、字体一件件翻出来，收进它的采集袋。**

- 中文名：超级爬爬熊
- 英文名：CrawlBear
- 用户：想从任意网页保存媒体素材的普通 macOS 用户
- 核心情绪：**可靠、憨厚、有点笨拙但很努力**。不是炫技的黑客工具，也不是冷冰冰的下载器。

## 2. 设计原则

1. **干净**：一屏只讲一件事。解释性文字能删就删，保留的是操作和状态。
2. **手绘**：粗墨线、圆角、轻微歪斜、贴纸投影。允许不完美，但不允许脏。
3. **憨厚**：小熊是主角，文案是它的口吻。动作叫「翻找」，下载叫「收进采集袋」。
4. **克制**：卡通感集中在插画、贴纸和动效上；排版与间距保持安静、有秩序。
5. **本机感**：界面像一本实体采集手账 / 工具箱，不出现云端、账号体系的视觉语言。

## 3. 视觉方向

### 3.1 关键词

木质玩具盒、蜡笔、邮票、贴纸、手账、蜂蜜罐、小熊背包。

### 3.2 明确不做

- 不做「奶油底 + 衬线大标题 + 砖红强调」的杂志风（这是上一版，已废弃）。
- 不做暗色 + 荧光强调色。
- 不做细线、零圆角的报纸风。
- 不用大量英文小字、编号、`FIELD NOTES` 这类编辑式装饰；说明文字不是装饰。

### 3.3 签名元素

**小熊「爬爬」+ 会说话的采集袋。** 它出现在首屏、空状态、爬取中、出错、完成这几个关键状态，用同一个角色、同一套面部表情延续叙事。它是界面上唯一可以「不克制」的地方。

### 3.4 质感

- 页面底色是奶油黄纸张，铺一张固定铺满视口的极淡纹样（约 90% 留白、低对比、少量爪印/圆点），丝纹样本身极淡（v2 干净版），其上只覆约 50% 的奶油色薄纱。
- 所有面板是贴在纸上的卡片：2.5px 墨线描边 + 4px 硬投影（无模糊），可带 ±0.4° 微旋转。
- 少量「手绘歪边框」：用不对称 `border-radius` 模拟手绘框，只用于 hero、空状态、下载袋三处。
- 底纹**不平铺**：一张 `cover` 固定背景铺满视口。手绘稀疏纹样一旦重复，接缝与镜像痕迹必然出现；改成单张铺满后从构造上消除接缝。
- 禁止大面积渐变；渐变只允许用于进度条「蜂蜜填充」一处。

### 4.4 间距 / 栅格

- 基准 4px。常用：8 / 12 / 16 / 20 / 28 / 36 / 56。
- 内容最大宽度 1080px，左右留白 32px（窄屏 20px）。
- 卡片网格：桌面 4 列，≥1280 五列，≤900 三列，≤640 两列。
- 页面纵向节奏：Hero 区 40px 上 / 28px 下；区块间距 32px。

## 5. 布局

### 5.1 首页（默认视图，单屏不滚动）

```
┌────────────────────────────────────────────────────────────┐
│ [App 图标] 超级爬爬熊        （ 翻找 ）（ 设置 ）            │  ← 固定顶栏
├────────────────────────────────────────────────────────────┤
│                                                            │
│   把网页里的宝贝                       ╭「今天想翻哪个网站？」│
│   收进采集袋。                         │  🐻 插画            │  ← Hero
│   图片、视频、音乐、字体，一次翻出来。  ╰───────────────╯    │
│                                                            │
│   ( 🌐  粘贴网页地址……                        [ 开始翻找 ] )  │  ← 一体式搜索胶囊
│                                                            │
└────────────────────────────────────────────────────────────┘
```

规则：

- **顶栏固定**，只有下方内容区域滚动；首页本身不滚动，一屏放下。
- Hero 只有标题、一句副文案、小熊与气泡；**没有标签、没有说明列表、没有空状态占位、没有页脚**。
- 输入框和按钮是**一个胶囊整体**：外壳一条墨线，内部无任何分隔线或线框；聚焦时外壳变浆果红。
- 用户可以不写协议，默认补 `https://`；localhost / IP 默认补 `http://`。
- 爬取中：同一屏显示蜂蜜色进度条；错误与提示**只走顶部浮层消息**，不插入页面。
- 爬取完成后整体切换到「结果页」，首页不保留结果。

### 5.2 结果页（独立页面，内部滚动）

```
┌────────────────────────────────────────────────────────────┐
│ [App 图标] 超级爬爬熊        （ 翻找 ）（ 设置 ）            │  ← 固定顶栏
├────────────────────────────────────────────────────────────┤
│ ← 再翻一页                                                 │
│ 百度一下，你就知道                                 [12 件]   │
│ www.baidu.com · baidu.com/                                 │
│ ─────────────────────────────────────────────────────────  │
│ [全部 12][图片 5][视频 2][音乐 3][字体 2]      ☑ 全选当前   │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐                                │
│ │卡片│ │卡片│ │卡片│ │卡片│   ← 点击卡片弹出预览窗          │
│ └────┘ └────┘ └────┘ └────┘                                │
│              ╭──────────────────────────────────╮          │
│              │ 🐻 已选 3 件       [ 收进采集袋 ] │          │  ← 吸底采集袋
│              ╰──────────────────────────────────╯          │
└────────────────────────────────────────────────────────────┘
```

- 结果页有自己的滚动容器，顶部「再翻一页」返回首页。
- 卡片点击 = 打开预览弹窗；左上角勾选框 = 选择（互不干扰）。
- 预览弹窗按类型渲染：图片大图、视频/音频播放器、字体样张；均带资源元信息。
- 批量下载栏吸底，始终显示「已选 N 件」；未选时按钮禁用，但栏不消失。

### 5.3 设置（独立页面，内部滚动）

```
设置
保存位置    [~/Downloads/CrawlBear]  [换一个] [打开]
翻找默认值  [图片][视频][音乐][字体]   并发 [－ 3 ＋]
           自动滚动 [开]   最多 [500] 件
登录站点    [https://…] [添加]
           · example.com          12 个 Cookie
             [打开登录] [清除]
关于        v0.3.2 · 本机运行 · 仅保存你有权下载的内容
```

规则：

- 每个设置块只留「贴纸标题 + 控件」，**不写说明文字**；设置页标题直接写「设置」。
- 删除 `01/02/03` 编号——这里不是有序流程。
- 页面内部滚动，保存条固定在底部；只有「有改动」时才高亮主按钮。
- 登录站点的添加框与按钮做成一体胶囊；站点条目和条目内按钮都不画边框，用底色和留白分隔。
- 站点卡片结构统一：左侧域名 + URL，右侧只显示「N 个 Cookie」（**不再判断是否已登录**，追踪 Cookie 会造成误判）；操作按钮单独占一行。
- 并发滑杆不显示黑色数值气泡，数值只出现在右侧徽章里。
- 清除登录态用居中确认弹窗，不用会重新定位的气泡。

## 6. 组件规范

### 6.1 按钮

- 主按钮：浆果红底、墨线 2.5px、白字、硬投影；hover 上移 1px + 投影 6px；按下回落。
- 次按钮：卡片底 + 墨线，hover 底色变 `--paper-deep`。
- 文字按钮：墨色下划线，hover 变浆果红。
- 高度：44px（标准）/ 48px（Hero 主行动）/ 32px（卡片内小按钮）。
- 图标按钮必须有 `aria-label`。

### 6.2 搜索胶囊

- 输入框 + 主按钮合成一个 999px 胶囊：外壳 2.5px 墨线 + 硬投影，内部无边框、无分隔线。
- 高 52px；左侧地球图标，右侧浆果红实心按钮；focus 时保留墨线描边，外加一圈柔和蜂蜜色光圈（5px / 42%），并做 280ms 过渡，不出现突兀的红框。
- 地址可省略协议，默认补 `https://`。
- 占位符只给一个例子，不写两段提示。

### 6.3 贴纸标签（kind chip）

- 胶囊形，2px 墨线，白底；激活时蜂蜜底 + 硬投影 + 轻微 `rotate(-1deg)`。
- 图标 + 名称 + 数字，数字放在右侧小圆里。
- 动效：点击 `scale(0.94)` 回弹。
- 筛选语义：在「全部」状态下点任一类型 = 只看该类型；再点同一类型回到全部；之后可继续叠加其他类型。数量为 0 的类型不可点。

### 6.4 资源卡片

- 2.5px 墨线、圆角 16px、硬投影；缩略图占 4:3，`object-fit: cover`。
- 左上角类型贴纸、右上角勾选戳、底部一行文件名 + 一行元信息（尺寸/时长/域名）。
- hover：`translateY(-3px) rotate(-0.6deg)` + 投影加深。
- 选中：浆果红描边 + 左上角贴纸变浆果红 + 勾选戳弹入（spring）。
- 状态：下载中显示旋转爪印；成功盖「已收」绿章；失败盖「漏了」红章。
- 卡片入场：按索引 stagger 12ms，spring 从下方 12px 弹起。

### 6.5 采集袋（批量下载栏）

- 吸底居中，最大宽 720px，手绘框 + 3px 墨线 + 6px 硬投影。
- 左侧小熊爪印徽章显示已选数量；数字变化时弹一下。
- 下载中：袋口显示当前文件名与百分比，进度条蜂蜜填充。
- 完成：袋子上出现「鼓鼓的」状态，可「在 Finder 中显示」。

### 6.6 小熊插画

- 组件 `<Mascot mood size />`，mood：`hero | idle | crawl | empty | happy | error | login`。
- 默认使用内置 SVG（见 `src/shared/components/Mascot.tsx`）；如果 `public/assets/bear-<mood>.png` 存在，优先使用生成图，加载失败自动回退 SVG。
- 插画不得带文字；文字一律走气泡组件。

### 6.7 系统级细节

- macOS 菜单栏：应用菜单（关于、设置、退出）+ 原生「编辑」菜单（撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选，中文标签 + 系统标准快捷键）；移除 File/View/Window/Help 等默认菜单。
- 全站禁用右键菜单；禁用文本选中（输入框除外），让界面更像原生应用。
- 进度条不使用虚线框；百分比居中显示在进度条内。

### 6.8 气泡

- 圆角 16px 白底 2.5px 墨线，尾巴用小三角，指向小熊。
- 位置固定在小熊头顶正上方，尾巴朝下指向脑袋；内容短句，最多 12 个汉字；文案见 §8。

## 7. 动效规范

引入 **framer-motion**，统一 spring 参数；所有动效必须响应 `prefers-reduced-motion`（组件内用 `useReducedMotion()`，CSS 用媒体查询）。

| 场景 | 动效 | 参数 |
| --- | --- | --- |
| 首屏 | 顶栏下落、Hero 文案上浮、小熊弹入 | 0.5s / spring stiffness 260 damping 22；小熊 delay 0.15s |
| 视图切换 | 旧视图淡出 120ms，新视图上浮 8px 淡入 | 0.32s ease-out |
| 小熊待机 | 上下浮动 6px、眨眼、耳朵轻摆 | 3.2s 循环，CSS |
| 爬取中 | 小熊左右张望 + 进度条蜂蜜流动，百分比数字居中并带暖色渐变流光，数值跳动时轻微弹入 | 2.4s / 2s 循环 |
| 结果出现 | 卡片 stagger 弹出 | spring stiffness 320 damping 26 |
| 勾选 | 勾选戳放大旋转弹入 + 卡片轻弹 | spring stiffness 500 damping 20 |
| 数量变化 | 数字徽章 scale 1 → 1.18 → 1 | spring |
| 首页 → 结果页 | 首页淡出上移，结果页淡入 | 0.26s |
| 下载完成 | 卡片盖「已收」章 + 采集袋摘要 + 爪印彩纸从采集袋上方落下 9 个 | 1.15s，一次性 |
| 错误 | 气泡文案切换 + 小熊左右张望（mascot error 姿态循环） | 2.4s 循环 |

**禁止**：整页粒子、连续闪烁、自动播放的复杂循环动画。动效服务状态，不服务炫技。

## 8. 文案声音

- 主语是「我」= 小熊；用户是「你」。
- 动作词固定：翻找（爬取）、收进采集袋（下载）、设置（设置）、采集袋（下载结果）。
- 一句话只做一件事：标题负责吸引，副文案负责说明，按钮负责动作。
- 不要感叹号堆叠，不用「请」「您」，不写免责长句。

关键文案表：

| 位置 | 文案 |
| --- | --- |
| Hero 标题 | 把网页里的宝贝，收进采集袋。 |
| Hero 副文案 | 图片、视频、音乐、字体，一次翻出来。 |
| 输入占位 | 粘贴网页地址或分享文字 |
| 主按钮 | 开始翻找 / 翻找中… |
| 空状态 | 袋子还空着。贴个网址，我这就去翻。 |
| 无结果 | 这页没翻到东西。换一页，或去设置登录后再试。 |
| 需要登录 | 这页要登录。去设置登录一下，我再来翻。 |
| 已选栏 | 已选 N 件 · 收进采集袋 |
| 下载完成 | 收好了，N 件都在袋子里。 |
| 出错 | 卡住了。再试一次，或看看网址能不能打开。 |

## 9. 插画与生图资产

生图原稿放在 `design-assets/`，经 `scripts/prepare_assets.py` 处理后输出到 `public/assets/`；文件名、尺寸、生图提示词见 [`docs/assets.md`](./assets.md)。

**约定**：在生成图到位之前，界面用内置 SVG 小熊保持完整；缺图自动回退，生成图经脚本处理后自动生效，无需改代码。

## 10. 可访问性

- 正文对比度 ≥ 4.5:1（`--ink-soft` 在卡片底上为 6.2:1）。
- 所有交互控件可键盘到达，`:focus-visible` 为 3px `--berry` 外描边。
- 卡片是 `role="button"`（回车预览），左上角独立按钮负责选择；选中状态同时有图标与色彩。
- 预览弹窗可用 Esc / 关闭按钮退出，焦点回到卡片。
- 动效遵循 `prefers-reduced-motion: reduce`：关闭位移与循环动画，保留透明度变化。
- 移动端 ≥ 640px 可用：Hero 变单列，小熊缩小到 160px，采集袋全宽。
